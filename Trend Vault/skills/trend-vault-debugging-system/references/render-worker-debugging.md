# Render Worker Debugging Reference

Use this file when the error involves any of these:
- `npm run sync:worker` crashing or hanging
- A render job failing (type: `render`)
- TTS generation failing
- Remotion hanging at 0% or crashing
- Script generation returning empty output or failing
- `npm run sync:test` showing `MISSING ✗`

## 1. Script Generation Errors

Script generation calls Claude API via `scripts/trend-vault-generate.ts`.
The worker spawns it as a child process using `npx tsx`.

### "Script generation failed (exit 1)"

**What it means:** The TypeScript script that calls Claude either crashed or
returned a non-zero exit code.

**Most common causes:**
- `ANTHROPIC_API_KEY` is missing or wrong in `.env`
- The `trend-vault-generate.ts` file has a syntax or import error
- The temp script file could not be written (working folder missing)

**How to diagnose:**
```bash
# Check if the key is set
node -e "require('dotenv').config(); console.log(process.env.ANTHROPIC_API_KEY ? 'KEY SET' : 'KEY MISSING')"

# Try running script gen manually
TREND_VAULT_SIGN=Scorpio npx tsx scripts/trend-vault-generate.ts
```

**Fix options:**
- Add `ANTHROPIC_API_KEY=sk-ant-...` to your `.env` file
- Or bypass script gen entirely: use `scriptLines` in your job JSON instead
  of the `script` block (no Claude needed)

---

### "Script parse failed"

**What it means:** The script ran but returned output that could not be parsed
as JSON.

**Common cause:** The Claude API returned an error message as text (like
`{"error": "rate limit"}`) instead of the expected script JSON.

**How to diagnose:** Add a temporary log before the `JSON.parse()` call in
`sync-worker.js` around line 213 to print `stdout` raw:
```js
console.log('RAW SCRIPT OUTPUT:', stdout.slice(0, 500));
```

## 2. TTS / Edge TTS Errors

TTS is generated by running `npx edge-tts` as a child process.
It requires internet access. It does NOT require an API key.

### "TTS generation failed" or "edge-tts: command not found"

**Check:**
```bash
npx edge-tts --version
```

If that fails, the package is not installed. Run:
```bash
npm install
```

### "TTS generation failed" with network error

Edge TTS calls Microsoft servers. Check internet connectivity.
The worker will continue and produce a silent video if TTS fails — this is
intentional. Check the log for `[WARN] TTS failed`.

### TTS produces silence / MP3 is 0 bytes

**Most common cause:** The text passed to edge-tts was empty or the temp
text file was not written.

**How to check:**
```bash
# Check if the temp text file was created
dir "C:\Trend Vault Program\working\tts_*.txt"
```

## 3. Remotion Render Errors

Remotion renders video by launching a headless Chrome/Edge browser.
It is the most resource-intensive step.

### "Render hangs at 0%" or no progress for over 2 minutes

**Most common cause:** Remotion cannot find Chrome or Edge on the machine.

**How to fix:**
```bash
# Check if Chrome is installed
where chrome
where msedge

# If neither is found, install Google Chrome from chrome.google.com
```

After installing Chrome, kill the stuck render and retry the job.

### "Cannot find composition" or "Composition not found: TrendVaultVideo"

**What it means:** Remotion cannot find the React component to render.
The bundle may need to be rebuilt.

**How to fix:**
```bash
npm run build
```
Then retry the job.

### "Out of memory" or render crashes after a few seconds

**What it means:** The machine ran out of RAM during rendering.

**Things to try:**
- Close other programs
- Reduce `fps` in the job settings from 60 to 30
- Reduce `targetDuration` to a shorter video

### Render produces a black video or empty frames

**Common causes:**
- Background video file does not exist in `backgrounds/` folder
- The `backgroundVideo` field in the job JSON has a typo

**How to check:**
```bash
dir "C:\Users\Anton\Desktop\Trend Vault Program\backgrounds"
```
Match the filename exactly (it is case-sensitive).

## 4. Worker Startup Errors

### "sync.config.json not found"

The worker could not find the config file. Run from the project root:
```bash
cd "C:\Users\Anton\Desktop\Trend Vault Program"
npm run sync:worker
```

### "ENOENT: no such file or directory" on a PATHS folder

The local folders have not been created yet. Run:
```bash
npm run setup:sync
```
This creates all folders under `C:\Trend Vault Program\` and the Drive bridge.

### Worker starts but immediately exits (no output)

The `console.log` calls inside `log()` should always print. If there is
absolutely no output, try running node directly:
```bash
node scripts/sync-worker.js --test 2>&1
```
If still silent, add a bare `console.log('STARTING')` at the very top of
`sync-worker.js` to confirm the file is being loaded.

## 5. Job File Errors

### "Unexpected token in JSON" when worker reads a job

The job JSON file has invalid syntax. Common mistakes:
- Trailing comma after the last field
- Missing quotes around a value
- Copied from an example that had comments (`//` is not valid in JSON)

**How to validate:**
```bash
node -e "JSON.parse(require('fs').readFileSync('path/to/job.json','utf8')); console.log('OK')"
```

### Job file is picked up but status never changes from `processing`

The worker crashed mid-job and left the status as `processing`. To retry:
1. Open the job JSON
2. Set `"status": "pending"`
3. Remove `"startedAt"`, `"error"`, `"failedAt"` if present
4. Save the file

### Worker picks up the same job repeatedly

This happens when `updateJob()` cannot write the updated status back to the
Drive file (Drive not synced, file locked, etc.). The worker uses an in-memory
`Set` to avoid running the same job twice per session, but this resets on
restart. Ensure Drive is synced and the `requests/` folder is writable.

## 6. Environment / API Key Errors

### How to check your `.env` file
```bash
# View keys (values will be shown — keep this private)
cat "C:\Users\Anton\Desktop\Trend Vault Program\.env"
```

Required keys by job type:

| Job type | Required key |
|----------|-------------|
| `render` (with AI script) | `ANTHROPIC_API_KEY` |
| `script-only` | `ANTHROPIC_API_KEY` |
| `clip` | `ASSEMBLYAI_API_KEY` |
| `render` (with `scriptLines`) | None |
| `tts` | None |

### Key format reference
```
ANTHROPIC_API_KEY=sk-ant-api03-...
ASSEMBLYAI_API_KEY=...
```

There should be no spaces around the `=` sign.
